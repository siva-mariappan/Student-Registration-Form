================================================================================
                    STEP 7: UPDATE BACKEND CORS (IMPORTANT!)
================================================================================

Your backend needs to allow requests from your Vercel frontend:

OPTION A: Update Locally and Push
----------------------------------

1. Open: backend/server.js

2. Find CORS configuration (around line 22):

   Current:
   ```javascript
   app.use(cors({
     origin: 'http://localhost:3000',
     credentials: true
   }));
   ```

3. Update to allow Vercel:

   ```javascript
   app.use(cors({
     origin: [
       'http://localhost:3000',
       'https://YOUR-VERCEL-URL.vercel.app'
     ],
     credentials: true,
     methods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
     allowedHeaders: ['Content-Type', 'Authorization']
   }));
   ```

4. Replace YOUR-VERCEL-URL with your actual Vercel URL!

5. Save, commit, and push:
   ```bash
   git add backend/server.js
   git commit -m "Add Vercel URL to CORS"
   git push origin main
   ```

6. Render will auto-redeploy (wait 3-5 minutes)

OPTION B: Use Environment Variable (Recommended for Production)
----------------------------------------------------------------

1. Add to Render environment variables:
   FRONTEND_URL=https://YOUR-VERCEL-URL.vercel.app

2. Update server.js to use it:
   ```javascript
   app.use(cors({
     origin: [
       'http://localhost:3000',
       process.env.FRONTEND_URL
     ].filter(Boolean),
     credentials: true
   }));
   ```

================================================================================
                    TROUBLESHOOTING
================================================================================

ISSUE 1: Build Failed - "Module not found"
-------------------------------------------
SOLUTION:
- Check Root Directory is set to: frontend
- Verify package.json exists in frontend folder
- Check all dependencies are in package.json

ISSUE 2: Build Failed - "npm command not found"
------------------------------------------------
SOLUTION:
- Vercel should auto-detect Node.js
- If not, add Build Command: npm install && npm run build

ISSUE 3: Blank Page After Deploy
---------------------------------
SOLUTION:
- Check browser console (F12) for errors
- Verify REACT_APP_API_URL is set correctly
- Make sure public/index.html exists
- Check Output Directory is: build

ISSUE 4: Google Login Fails - redirect_uri_mismatch
----------------------------------------------------
SOLUTION:
- Add Vercel URL to Google Cloud Console
- Format: https://your-project.vercel.app (no trailing slash)
- Wait 5 minutes after updating
- Try incognito mode

ISSUE 5: "Failed to fetch" or Network Errors
---------------------------------------------
SOLUTION:
- Backend CORS not allowing Vercel URL
- Update backend/server.js with your Vercel URL
- Push to GitHub
- Wait for Render to redeploy

ISSUE 6: Old Version Still Showing
-----------------------------------
SOLUTION:
- Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
- Clear browser cache
- Try incognito mode
- Check Vercel deployment status

ISSUE 7: Environment Variable Not Working
------------------------------------------
SOLUTION:
- Must start with REACT_APP_
- Redeploy after adding variables
- Check spelling: REACT_APP_API_URL (not REACT_APP_API_URl)
- No quotes around value in Vercel dashboard

================================================================================
                    AUTOMATIC DEPLOYMENTS
================================================================================

Vercel automatically deploys when you push to GitHub:

1. PRODUCTION DEPLOYMENTS
   - Triggered by: Push to main branch
   - URL: your-project.vercel.app

2. PREVIEW DEPLOYMENTS
   - Triggered by: Pull requests or other branches
   - URL: your-project-git-branchname.vercel.app
   - Great for testing before merging

3. HOW IT WORKS

   You make changes → Git push → Vercel auto-deploys!

   ```bash
   # Make changes to code
   git add .
   git commit -m "Update feature"
   git push origin main

   # Vercel automatically:
   # 1. Detects push
   # 2. Starts build
   # 3. Deploys new version
   # 4. Updates live site
   ```

4. DEPLOYMENT NOTIFICATIONS
   - Check your email
   - Visit Vercel dashboard
   - GitHub commit shows deployment status
