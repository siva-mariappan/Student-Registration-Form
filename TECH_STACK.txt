================================================================================
                              API ARCHITECTURE
================================================================================

API STYLE:
  • RESTful API                - REST architectural style

ENDPOINTS:
  Authentication:
    • POST   /auth/google                    - Initiate Google OAuth
    • GET    /auth/google/callback           - OAuth callback handler
    • GET    /auth/current-user              - Get logged-in user
    • GET    /auth/logout                    - Logout user

  Students:
    • POST   /api/students                   - Register new student (protected)
    • GET    /api/students/:id               - Get student by ID (protected)

HTTP METHODS:
  • GET                        - Retrieve data
  • POST                       - Create data
  • PUT/PATCH                  - Update data (future)
  • DELETE                     - Delete data (future)

================================================================================
                            DATABASE SCHEMA
================================================================================

COLLECTIONS:
  1. users                     - Authenticated users (Google accounts)
     - googleId (String)       - Unique Google ID
     - email (String)          - User email
     - name (String)           - Display name
     - picture (String)        - Profile picture URL
     - createdAt (Date)        - Registration timestamp

  2. students                  - Student registration records
     - fullName (String)       - Student full name
     - email (String)          - Student email (unique)
     - phoneNumber (String)    - Contact number
     - dateOfBirth (Date)      - Birth date
     - gender (String)         - Male/Female/Other
     - address (String)        - Residential address
     - course (String)         - Program/Course name
     - yearSemester (String)   - Academic year/semester
     - parentGuardianContact   - Emergency contact
     - createdAt (Date)        - Registration timestamp

  • Frontend Server            - http://localhost:3000
  • MongoDB Atlas              - Cloud (port 27017 internally)
