================================================================================
        FIX: Login Works But Registration Form Doesn't Show
================================================================================

PROBLEM:
✓ Google OAuth login works
✓ Google accepts the login
✗ After login, registration form page doesn't appear

POSSIBLE CAUSES:
1. Redirecting to localhost instead of production URL
2. CORS blocking frontend-backend communication
3. Environment variables not set correctly
4. Session cookies not working

================================================================================
FIX 1: CHECK WHERE YOU'RE BEING REDIRECTED
================================================================================

After you click "Sign in with Google" and complete login, check the browser
address bar.

SCENARIO A: You see localhost in the URL
─────────────────────────────────────────
Example: http://localhost:3000

PROBLEM: OAuth is redirecting to localhost instead of production

FIX:
1. Go to Render dashboard: https://dashboard.render.com
2. Click on your backend service
3. Go to Environment tab
4. Find: FRONTEND_URL
5. Make sure it's set to: https://your-vercel-app.vercel.app (NOT localhost)
6. Save Changes
7. Wait for auto-redeploy (2-3 minutes)

SCENARIO B: You see your Vercel URL but blank/loading page
─────────────────────────────────────────────────────────
Example: https://your-app.vercel.app (but shows blank or loading forever)

PROBLEM: Frontend can't communicate with backend

FIX: See Fix 2 below

================================================================================
FIX 3: CHECK BROWSER CONSOLE FOR ERRORS
================================================================================

1. After login, when you're on the blank/stuck page
2. Press F12 (or right-click → Inspect)
3. Click "Console" tab
4. Look for RED error messages

COMMON ERRORS AND FIXES:

ERROR: "CORS policy: No 'Access-Control-Allow-Origin' header"
FIX: FRONTEND_URL on Render doesn't match your actual Vercel URL

ERROR: "Failed to fetch" or "Network request failed"
FIX: REACT_APP_API_URL on Vercel is wrong or backend is down

ERROR: "Refused to connect" or "ERR_CONNECTION_REFUSED"
FIX: Backend is not running or URL is wrong

ERROR: 401 Unauthorized or "Not authenticated"
FIX: Session cookies not working (see Fix 4)

================================================================================
FIX 4: CLEAR BROWSER CACHE AND TEST IN INCOGNITO
================================================================================

Old cookies and cache can cause issues:

1. Clear browser data:
   Chrome: Settings → Privacy → Clear browsing data
   - Select "Cookies" and "Cached images"
   - Time range: "All time"
   - Click "Clear data"

2. Open NEW incognito/private browser window

3. Go to your Vercel URL

4. Try logging in again

================================================================================
FIX 5: VERIFY GOOGLE OAUTH CONSOLE SETTINGS
================================================================================

Go to: https://console.cloud.google.com/apis/credentials

Click on your OAuth 2.0 Client ID

Make sure you have:

Authorized JavaScript origins:
✓ https://your-vercel-app.vercel.app
✓ https://student-registration-form-ar1g.onrender.com

Authorized redirect URIs:
✓ https://student-registration-form-ar1g.onrender.com/auth/google/callback

(Keep localhost ones too for local development)

================================================================================
FIX 6: TEST YOUR BACKEND API DIRECTLY
================================================================================

1. After you login with Google, immediately go to this URL in a new tab:
   https://student-registration-form-ar1g.onrender.com/auth/current-user

2. You should see something like:
   {
     "success": true,
     "user": {
       "id": "...",
       "name": "Your Name",
       "email": "youremail@gmail.com",
       "picture": "..."
     }
   }

3. If you see this: ✓ Backend authentication is working!
   Problem is in frontend communication

4. If you see {"success": false, "user": null}:
   Problem: Session not persisting
   Fix: Check NODE_ENV=production on Render

================================================================================
FIX 7: CHECK RENDER LOGS FOR ERRORS
================================================================================

1. Go to Render dashboard: https://dashboard.render.com
2. Click on your backend service
3. Click "Logs" in left sidebar
4. Look for errors after you try to login

Common log errors:

"MongoDB connection failed" → MONGODB_URI is wrong
"Session error" → SESSION_SECRET missing
