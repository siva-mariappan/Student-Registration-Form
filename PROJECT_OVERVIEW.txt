================================================================================
                          EXECUTIVE SUMMARY
================================================================================

The Student Registration System is a modern, full-stack web application
designed to streamline the process of student enrollment and data management
for educational institutions. Built using the MERN stack (MongoDB, Express,
React, Node.js) with Google OAuth 2.0 authentication, it provides a secure,
user-friendly interface for registering and retrieving student information.

PROJECT TYPE:        Full-Stack Web Application
TARGET USERS:        Educational Administrators, Registrars, Academic Staff
DEVELOPMENT STATUS:  Production-Ready (v1.0)
DEPLOYMENT:          Local Development / Cloud-Ready

================================================================================
                          USER JOURNEY
================================================================================

STEP 1: ACCESS APPLICATION
  User visits: http://localhost:3000
  Sees: Professional login page with Google Sign-In button

STEP 2: AUTHENTICATION
  User clicks: "Sign in with Google"
  Action: Redirected to Google OAuth consent screen
  Result: Selects Google account and authorizes access

STEP 3: MAIN DASHBOARD
  User sees: Student Registration form and Retrieve section
  Header shows: User profile picture, name, email, and logout button

STEP 4: REGISTER STUDENT
  User fills: All 9 required student fields
  Clicks: "Submit Registration" button
  System: Validates data and saves to database
  Feedback: Success message with generated Student ID

STEP 5: RETRIEVE STUDENT
  User enters: Student ID in retrieve section
  Clicks: "Retrieve Student" button
  System: Fetches data from database
  Display: Complete student information card

STEP 6: LOGOUT
  User clicks: "Logout" button in header
  System: Ends session and redirects to login page

================================================================================
                          USE CASES
================================================================================

USE CASE 1: NEW STUDENT ENROLLMENT
  Actor: Academic Administrator
  Goal: Register a new student in the system

  Steps:
    1. Admin logs in with Google account
    2. Fills out student registration form
    3. System validates all fields
    4. Admin submits the form
    5. System generates unique Student ID
    6. Success message displayed with ID
    7. Form resets for next student

  Result: Student successfully registered in database

USE CASE 2: STUDENT INFORMATION LOOKUP
  Actor: Academic Staff Member
  Goal: Find and view a student's information

  Steps:
    1. Staff member logs in with Google account
    2. Navigates to "Retrieve Student Data" section
    3. Enters Student ID
    4. Clicks "Retrieve Student" button
    5. System queries database
    6. Student information displayed

  Result: Staff member views complete student profile

USE CASE 3: MULTI-USER ACCESS
  Actor: Multiple administrators
  Goal: Multiple staff members access system simultaneously

  Steps:
    1. Each admin logs in with their own Google account
    2. All users can register and retrieve students
    3. System maintains separate sessions
    4. No data conflicts occur

  Result: Concurrent access without issues

================================================================================
                          INSTALLATION & SETUP
================================================================================

QUICK START (5 MINUTES):

1. GOOGLE OAUTH SETUP
   • Go to: https://console.cloud.google.com/apis/credentials
   • Create OAuth 2.0 credentials
   • Add authorized origins: http://localhost:3000, http://localhost:5001
   • Add redirect URI: http://localhost:5001/auth/google/callback
   • Copy Client ID and Secret

2. BACKEND SETUP
   • Navigate to: /backend folder
   • Run: npm install
   • Create: .env file with credentials
   • Run: npm start

3. FRONTEND SETUP
   • Navigate to: /frontend folder
   • Run: npm install
   • Run: npm start

4. ACCESS APPLICATION
   • Open: http://localhost:3000
   • Login: Click "Sign in with Google"
   • Use: Register and retrieve students!

================================================================================
                          API ENDPOINTS
================================================================================

AUTHENTICATION ENDPOINTS:
  GET  /auth/google
       Description: Initiates Google OAuth flow
       Access: Public
       Response: Redirects to Google login

  GET  /auth/google/callback
       Description: Handles OAuth callback
       Access: Public (via Google)
       Response: Redirects to frontend with session

  GET  /auth/current-user
       Description: Returns current logged-in user
       Access: Public
       Response: User object or null

  GET  /auth/logout
       Description: Logs out current user
       Access: Authenticated
       Response: Success message

STUDENT ENDPOINTS:
  POST /api/students
       Description: Register new student
       Access: Protected (requires authentication)
       Body: Student data (9 fields)
       Response: Created student with ID

  GET  /api/students/:id
       Description: Get student by ID
       Access: Protected (requires authentication)
       Params: MongoDB ObjectId
       Response: Student object or 404 error

TROUBLESHOOTING COMMON ISSUES:

  1. Login not working
     → Check Google OAuth credentials
     → Verify authorized origins/redirect URIs
     → Check backend is running on port 5001

  2. Can't register students
     → Verify user is logged in
     → Check all required fields filled
     → Ensure no duplicate email
     → Check MongoDB connection

  3. Can't retrieve students
     → Verify Student ID format (24 hex characters)
     → Check database connection
     → Ensure student exists in database

  4. Session expires too quickly
     → Adjust maxAge in server.js session config
     → Check cookie settings
