7. TROUBLESHOOTING
================================================================================

Problem: "Port 5001 is already in use"
Solution:
lsof -ti:5001 | xargs kill -9
Then restart the server.

Problem: "MongoDB connection failed"
Solution:
- Verify MONGODB_URI is correct
- Check MongoDB Atlas network access (allow your IP)
- Ensure MongoDB cluster is running

Problem: "Google OAuth Error 401: invalid_client"
Solution:
- Verify GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET
- Check Authorized Redirect URIs in Google Console
- Ensure OAuth consent screen is configured

Problem: "Session not persisting"
Solution:
- Verify SESSION_SECRET is set
- Check that connect-mongo is properly configured
- Ensure cookies are enabled in browser

Problem: "CORS errors from frontend"
Solution:
- Verify CORS is configured in server.js
- Check origin is set to frontend URL
- Ensure credentials: true in CORS config
