================================================================================
        CONNECTING VERCEL FRONTEND TO RENDER BACKEND
================================================================================

STEP 1: GET YOUR RENDER BACKEND URL
====================================

1. Go to Render Dashboard:
   https://dashboard.render.com/

2. Click on your backend service
   (Something like: student-registration-backend)

3. Look at the top of the page for your URL:
   https://your-service-name.onrender.com

4. Copy this entire URL!

Example URLs:
- https://student-registration-backend.onrender.com
- https://student-backend-abc123.onrender.com
- https://my-api-xyz789.onrender.com

📝 WRITE YOUR URL HERE:
https://_________________________________.onrender.com


STEP 2: ADD TO VERCEL ENVIRONMENT VARIABLES
============================================

1. Go to Vercel Dashboard:
   https://vercel.com/dashboard

2. Click on your project
   (Student-Registration-Form or whatever you named it)

3. Click "Settings" tab (top navigation)

4. Click "Environment Variables" (left sidebar)

5. Click "Add New" button

6. Fill in:
   NAME (exactly as shown):
   REACT_APP_API_URL

   VALUE (your Render URL):
   https://your-backend-name.onrender.com

   IMPORTANT:
   - Use HTTPS (not HTTP)
   - NO trailing slash at the end
   - Must be the complete URL

   ✅ Good: https://my-backend.onrender.com
   ❌ Bad:  https://my-backend.onrender.com/
   ❌ Bad:  http://my-backend.onrender.com

7. Select all environments:
   ✓ Production
   ✓ Preview
   ✓ Development

8. Click "Save"

9. REDEPLOY:
   - Go to "Deployments" tab
   - Click "..." menu on latest deployment
   - Click "Redeploy"
   - Wait 2-3 minutes


STEP 3: UPDATE BACKEND CORS
============================

Your backend needs to allow requests from Vercel.

METHOD A: Using Environment Variable (Recommended)
---------------------------------------------------

1. Go to Render Dashboard
2. Click your backend service
3. Click "Environment" tab (left sidebar)
4. Click "Add Environment Variable"
5. Add:
   NAME: FRONTEND_URL
   VALUE: https://your-project-name.vercel.app

6. Click "Save Changes"
7. Wait for auto-redeploy (3-5 minutes)

8. Update your backend/server.js code:

```javascript
// Backend: server.js
app.use(cors({
  origin: [
    'http://localhost:3000',
    process.env.FRONTEND_URL
  ].filter(Boolean),
  credentials: true,
  methods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));
```

9. Commit and push to GitHub:
```bash
git add backend/server.js
git commit -m "Add dynamic CORS configuration"
git push origin main
```

METHOD B: Hardcode URL (Quick but not ideal)
---------------------------------------------

Update backend/server.js directly:

```javascript
// Backend: server.js
app.use(cors({
  origin: [
    'http://localhost:3000',
    'https://your-project-name.vercel.app'
  ],
  credentials: true,
  methods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));
```

Replace 'your-project-name.vercel.app' with your actual Vercel URL!

Then commit and push:
```bash
git add backend/server.js
git commit -m "Update CORS for production"
git push origin main
```

Render will auto-redeploy (3-5 minutes)


STEP 4: UPDATE GOOGLE OAUTH
============================

Add both your production URLs to Google Cloud Console:

1. Go to Google Cloud Console:
   https://console.cloud.google.com/apis/credentials

2. Click on your OAuth 2.0 Client ID

3. AUTHORIZED JAVASCRIPT ORIGINS:
   
   Add these URLs (keep existing localhost ones):
   
   http://localhost:3000
   http://localhost:5001
   https://your-backend.onrender.com
   https://your-project.vercel.app

4. AUTHORIZED REDIRECT URIS:
   
   Add:
   
   http://localhost:5001/auth/google/callback
   https://your-backend.onrender.com/auth/google/callback

5. Click "SAVE"

6. ⏱️ WAIT 5 MINUTES for changes to propagate


STEP 5: UPDATE BACKEND REDIRECT URL
====================================

Update your backend to redirect to Vercel after login:

1. Edit: backend/routes/authGoogleRoutes.js

2. Find the callback route (around line 19):

```javascript
router.get('/google/callback',
  passport.authenticate('google', {
    failureRedirect: 'http://localhost:3000'
  }),
  (req, res) => {
    // Update this line:
    const frontendUrl = process.env.FRONTEND_URL || 'http://localhost:3000';
    res.redirect(`${frontendUrl}?login=success`);
  }
);
```

3. Save, commit, and push:
```bash
git add backend/routes/authGoogleRoutes.js
git commit -m "Add dynamic frontend redirect"
git push origin main
```

4. Render will auto-redeploy


STEP 6: TEST THE CONNECTION
============================

1. Open your Vercel URL:
   https://your-project.vercel.app

2. Open browser DevTools (F12)

3. Go to "Network" tab

4. Click "Sign in with Google"

5. Check network requests:
   
   You should see requests to:
   ✓ https://your-backend.onrender.com/auth/google
   ✓ Status: 302 (redirect)
   ✓ No CORS errors

6. Complete Google login

7. After redirect, check:
   ✓ https://your-backend.onrender.com/auth/current-user
   ✓ Status: 200
   ✓ Response contains your user data

8. Try registering a student:
   ✓ POST to https://your-backend.onrender.com/api/students
   ✓ Status: 201
   ✓ Success message appears

9. Try retrieving a student:
   ✓ GET to https://your-backend.onrender.com/api/students/:id
   ✓ Status: 200
   ✓ Student data displays


TROUBLESHOOTING CONNECTION ISSUES
==================================

ISSUE: "Failed to fetch" errors
SOLUTION:
- Check REACT_APP_API_URL in Vercel is correct
- Verify backend CORS includes Vercel URL
- Make sure backend is running (visit backend URL)
- Check browser console for specific error

ISSUE: CORS errors
SOLUTION:
- Update backend/server.js CORS configuration
- Add your Vercel URL to allowed origins
- Push to GitHub and wait for Render redeploy
- Clear browser cache and try again

ISSUE: redirect_uri_mismatch
SOLUTION:
- Add Vercel URL to Google OAuth authorized origins
- Add backend/auth/google/callback to redirect URIs
- Wait 5 minutes after saving
- Try incognito mode

ISSUE: Backend connection timeout
SOLUTION:
- Render free tier sleeps after 15 minutes
- First request takes 30-60 seconds to wake up
- Subsequent requests are fast
- Consider upgrading to paid tier for always-on

ISSUE: Environment variable not working
SOLUTION:
- Verify it starts with REACT_APP_
- Check spelling: REACT_APP_API_URL
- Redeploy after adding variable
- Hard refresh browser (Cmd+Shift+R)

SUMMARY: THE CONNECTION FLOW
=============================

1. User visits: https://your-project.vercel.app
2. React app loads with REACT_APP_API_URL
3. User clicks "Sign in with Google"
4. Request goes to: https://your-backend.onrender.com/auth/google
5. Redirects to Google OAuth
6. User authorizes
7. Google redirects to: https://your-backend.onrender.com/auth/google/callback
8. Backend creates session
9. Redirects to: https://your-project.vercel.app?login=success
10. Frontend checks: https://your-backend.onrender.com/auth/current-user
11. User is logged in!
12. All API calls go to backend with session cookie

This works because:
✓ CORS allows Vercel origin
✓ Credentials: true allows cookies
✓ Google OAuth allows both URLs
✓ Session persists across requests
